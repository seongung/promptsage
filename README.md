# Prompt Sage TUI

Prompt Sage is a terminal user interface for exploring, filtering, and reviewing prompts from local Claude / Codex transcript logs.

<img width="1512" height="982" alt="image" src="https://github.com/user-attachments/assets/9328e075-a6df-42d5-8f11-e7416b2b97b7" />

The screenshot above shows the main workflow:

- Browse prompts with filters for provider, project, date, and review status.
- See the original prompt alongside the suggested “Sage” rewrite.
- Queue individual or bulk reviews, then export or copy improved prompts for further use.
- #Use your existing Claude / Codex subscription via their CLIs — no extra API setup or per-token billing beyond what you already pay for.
